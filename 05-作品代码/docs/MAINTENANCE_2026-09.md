## 1. 背景与问题定位

用户反馈学情诊断中出现**两道完全相同的题目**（题干、选项、考点、溯源逐字一致）。经日志-代码-截图三方比对，确认根因链：

1. 工作流侧的持久化"状态"变量（用于情景演绎路由）一旦置 `1` 未复位，会把后续**所有**请求劫持进情景演绎支线；
2. 被劫持的出题请求收到的是工作流内置示例/旧指令回显，被适配器防泄露网拦截后内容为空；
3. 旧版适配器在内容为空时**静默塞入一段写死的本地题库**（且无去重），两次失败即两道一模一样的题。

进一步排查发现该平台的"保底欺骗"不止一处，共清理 8 处（见第 2 节），并顺带修复了成绩册回写从未真正打通的隐藏断点（见第 3 节）。

## 2. 保底伪造机制清理（8 处）

| 位置 | 原行为（欺骗性） | 现行为（诚实） |
| :--- | :--- | :--- |
| `extract_quiz_meta_fallback` | 解析失败时按关键词命中本地写死题库（6 套整题），否则默认"响应速度排序"题 | 仅做解析；解析不出即判失败，绝不造题 |
| 答案推断 | 题面含"抽水蓄能"猜 A、"全钒"猜 A、"压缩空气"猜 B 等 | 无答案字母即判出题失败；`is_usable_quiz_meta` 强制要求 A-D 答案 |
| 课件溯源推断 | 按关键词虚构"3.4 PCS.pdf P12"式引用与解析 | 模型未给出处则留空；判分时课件引用必须通过白名单核验 |
| 诊断判分 | 无答案时默认正确答案 B | 停止判分并如实提示"答案数据异常" |
| 随堂判分 | 无法解析作答时默认学生选 A | 如实请学生回复选项字母 |
| 终局诊断报告 | 上游失败时输出伪造的 3000 字模板报告（含虚构页码推荐） | 重试一次；仍失败则输出基于真实作答记录的确定性统计，明示"非 AI 生成" |
| 情景开场白 ×2 | 上游失败时静默替换为写死的张师傅/名师开场白 | 重试一次 + 回滚本地情景状态 + 诚实提示 |
| 前端网络异常 | catch 分支注入一段写死的"PCS/调频死区"回答并附虚构课件引用 | 提示"服务不可达，未生成任何回答，请重试" |

另删除从未被调用但具备伪造风险的死代码 `build_teacher_fallback_answer`。

## 3. 成绩册回写修复（三处断点）

教师批改后的"Moodle 成绩册同步"此前从未成功（文档曾宣称已验证）：

1. `grade-sync.php` 从未装进 Moodle 镜像（文件在 `deploy/moodle/` 根目录，构建上下文只 COPY `local/course_agent/`），运行时 404；
2. PHP 脚本 `grade_update` 参数位错传 + 成绩数组缺 `userid` 键，且 `grade_update` 的 raw-grade 写入路径只支持 `itemtype=mod`，人工成绩项必须走成绩册 API（`grade_item` + `update_final_grade`）；
3. Moodle AJAX 异常被包装成 HTTP 200 错误体，适配器只看状态码误判"已同步"——现校验响应体 `status=synced`；PHP 侧加 try/catch 返回真实 5xx；内网调用补公网 Host 头避免会话引导重定向。

修复后实测：教师批改 → `moodle_sync: synced` → MySQL `grade_grades` 表出现真实成绩行，学生端可见。

## 4. 工作流对接可靠性机制

讯飞工作流（`7494978072491315200`）存在持久化状态变量与 6 轮决策记忆，偶发误路由。适配器现具备完整的识别-复位-重试链路：

| 机制 | 触发特征 | 动作 |
| :--- | :--- | :--- |
| 指令回显拦截 `workflow_prompt_echo_rejected` | 返回内容含提示词包装标记 | 向工作流发送"退出情景演绎"复位持久状态，再重试 |
| 告别语识别 `looks_like_scenario_farewell` | 纯"已退出情景演绎/已停止出题"类应答且无题干 | 同上复位 + 重试 |
| 占位引用剥离 | 合格内容附带 `[来源文件：xxx.pdf；页码：yyy]` | 只剥离占位引用，保留正文（内置演示对话由"学生:/老师:"对话体特征拦截） |
| 答案探针恢复 `recover_missing_quiz_answer` | 题目有完整选项但缺答案字母（工作流结束节点未绑定答案变量所致） | 向批改分支发一次探针作答，从"标准正确选项为 X"取回工作流自己算出的真实答案；探针应答不展示 |
| 会话内去重 `asked_stems` | 新题干（归一化后）与已出题重复 | 带禁出清单定向重试 |
| 待出题状态 `awaiting_next` | 下一题生成失败但作答已记分 | 保留记录；学生回复"下一题"即补发新题，回复"生成诊断报告"可提前结束 |
| 出题缓冲验证 | 全部四条出题路径（诊断首题/下一题/补发/随堂） | 首稿缓冲→验格→不合格静默重试一次→只展示合格题；两次失败仅诚实提示 |
