# 电力系统储能技术课程 Agent 平台伦理与安全声明

本作品用于电力系统储能技术课程的教学辅助，不替代教师、教材、实验规范或工程安全审批。平台将生成内容明确标记为 AI 生成内容，专业结论必须结合课程来源核验。

平台只处理课程所需的 Moodle 身份和学习记录。进入课程被定义为有效登录和页面打开，不采集摄像头、麦克风或隐式行为画像。传给讯飞 Workflow 的用户标识为服务器端 HMAC 生成的伪匿名 UID，不包含姓名或学号；API Key、API Secret 只保存在服务器端环境变量中。

Agent 只允许使用已发布的课程 Workflow 和知识库。来源文件、章节和页码必须与本地 manifest、哈希和 Moodle 资源映射一致；无法核验时显示“来源待核验”，不补造文献、实验数据或页码。情景演绎中的数值均标记为模拟数据，不可直接用于真实电力系统操作。

成绩、作业状态、学习状态和权限由服务端规则和教师审核决定，不能由模型自由文本覆盖。客观题使用固定答案确定性评分；主观题的 Agent 初评必须通过结构化格式和分值范围校验，并保留教师复核、修改原因和审计记录。

教师、学生和管理员执行对象级权限隔离。上传文件限制类型、大小、文件名和存储目录；页面以纯文本或安全白名单渲染用户输入和 Agent 输出。所有服务、课程数据、知识图谱和版本记录纳入备份与恢复演练，明文密钥不进入代码、前端、日志或备份。

发现专业错误、来源错误、越权、隐私泄露、密钥泄露或无法恢复数据时，立即停止 Demo 使用并进入人工复核；平台不把 Mock Workflow 结果作为真实讯飞主链路证据。
