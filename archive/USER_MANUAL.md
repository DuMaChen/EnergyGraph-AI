## 附录：系统管理员后台维护指南（管理员专用）

本部分供系统管理员维护网站后台大模型连接与系统设置使用：

### 1. 大模型连接设置（讯飞星火 Spark API / 星辰工作流）
1. 登录管理员账号（`admin` / `Moodle2026!`），进入 **“教师工作台” -> “运维与模型配置”**；
2. 填入大模型接口凭证（`APPID`、`APISecret`、`APIKey`、模型版本与温度值）；
3. 点击 **`连通性检查`** 确保大模型与教务接口通信畅通；
4. 点击 **`保存服务配置`** 立即全局生效。

### 2. 在线修改 AI 助教的说话规范与出题规则
管理员可以在“AI 说话与出题要求设置”区域在线调整大模型在不同场景下的约束规则：
- **核心回答要求**：要求全局使用标准 LaTeX 公式排版并附带课件页码；
- **学生答疑要求**：要求采用苏格拉底启发式引导；
- **题库出题要求**：要求生成合法的题干、选项、答案与解析结构；
- 若配置有误，点击 **`恢复默认规则`** 可一键还原出厂预设。

### 3. 清理网站缓存与广播作业提醒
- 点击 **`清理缓存`**：即时清除过期前端缓存并重建课件索引；
- 点击 **`发布系统通知`**：向全班所有注册学生推送作业截止提醒广播。
