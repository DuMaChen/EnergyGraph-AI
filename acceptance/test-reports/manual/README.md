# 人工验收记录

本目录只保存真实浏览器、真实测试账号和真实讯飞 Workflow 的验收记录。
本地 Mock、回环 HTTP 夹具和自动化协议测试必须放在 `../automated/`，不能
把它们复制成“人工通过”证据。

## 使用规则

1. 每个验收编号单独建立一个 Markdown 文件，例如 `STUDENT-001-course.md`。
2. 同一文件记录输入、原始输出、来源、内部 request ID、讯飞 sid（如有）和证据路径。
3. 截图或录屏不得包含 API Key、API Secret、真实学号、真实姓名或其他无关隐私。
4. 专业教师必须逐条核验关键事实和来源页码；只看最终页面截图不能替代核验。
5. 失败记录不得删除或覆盖；修复后新建复测记录并关联原始失败记录。

## 必须完成的记录

- `STUDENT-001` 至 `STUDENT-005`：学生课程、问答、多轮、学习路径和安全边界。
- `TEACHER-001` 至 `TEACHER-003`：备课、出题和生成内容修改。
- `ADMIN-001`：服务、知识库版本、备份和恢复检查。
- `SEC-REAL-001`：真实浏览器密钥、权限、CSRF、错误和日志检查。
- `CASE-001` 至 `CASE-006`：正式案例的真实 Workflow 结果和专业复核。

在星辰凭据、真实账号和正式域名尚未到位前，这些记录只能保留空模板，不能填写“通过”。
